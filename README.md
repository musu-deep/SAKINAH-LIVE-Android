# SAKINAH LIVE — Android

Standalone Qur'an live-broadcast studio for Android.

- Portrait 9:16 animated Qur'an scene
- SUKOON / NOOR / FAJR themes
- Local recitation audio, microphone, or mixed audio
- Direct RTMP / RTMPS publishing from the phone
- Android screen-capture broadcast via MediaProjection

## Build

GitHub Actions builds the debug APK automatically on pushes to `main`.
Download the `SAKINAH-LIVE-APK` artifact from the latest successful Actions run.

Current app version: 1.4.0
